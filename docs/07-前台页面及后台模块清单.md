# 前台页面及后台模块清单

> 来源：`public/` 目录、`public/_worker.js`、`public/assets/js/admin.js`。

## 一、公开前台

### 1. 静态页面（ASSETS 直接服务）

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 首页 | `public/index.html` | Hero + 4 个免费知识库栏目卡（静态链接）+ 「最新免费文章」4 条静态文章 + 案例区（`site.js` 动态加载） |
| 会员登录 | `public/member/index.html` + `member-login.js` | 访问码登录 |
| 静态文章 | `public/guide/90-day-roadmap.html`、`public/products/validation.html`、`public/build/shopify-day-one.html`、`public/marketing/first-ad.html` | 早期静态文章，完整文件名可访问 |
| 工具页 ×5 | `public/tools/{pricing,ads,profit,calendar,ai-sourcing}/index.html` | 经 Worker 鉴权后放行 |
| favicon / robots | `public/favicon.svg`、`public/robots.txt` | |

> 注意：`public/guide/index.html` 等 4 个栏目 index.html 已被 Worker 动态路由（`/guide/` 等）拦截，**静态文件实际不生效**，属冗余文件。

### 2. 动态页面（Worker SSR，`publicShell` 统一页头页脚）

| 路由 | 处理函数 | 权限 |
| --- | --- | --- |
| `/courses/`（`/library/` 同） | `handlePublicCourseList` | 公开，免费+已发布课程 |
| `/library/<slug>/` | `handlePublicLibrary` | free 公开；member 302 去登录 |
| `/guide/`、`/products/`、`/build/`（`/tutorials/` 别名）、`/marketing/` | `handleNavSection` | 公开栏目页，按 `nav_category` 过滤 |
| `/cases`、`/cases/<slug>/` | `handlePublicCaseList` / `handlePublicCaseDetail` | 公开，published 案例 |
| `/tools/<slug>/` | `handleToolPage` | 工具页鉴权放行 |
| `/media/<name>.<ext>` | `handleMedia` | 公开图片 |
| `/courses/<slug>/attachment` | `handleContentAttachment` | 课程附件下载 |

## 二、会员中心（`memberShell` 统一布局，全部 SSR）

| 路由 | 函数 | 内容 |
| --- | --- | --- |
| `/member/app/` | `renderMemberHome` | 欢迎卡（编号+VIP会员）、课程/SOP/资料/更新概览 |
| `/member/app/courses/` | `renderCourseIndex` | 全部已发布课程按分类分组（含未分类） |
| `/member/app/courses/<slug>` | `renderCourseDetail` | 课程正文/章节、附件下载、同分类上下篇 |
| `/member/app/resources/` | `renderResourceList` | 全部已发布资料 + 下载 |
| `/member/app/sop/` | `renderResourceList`(slugs=[sop,prompt]) | 按分类过滤的 SOP 资料 |
| `/member/app/updates/` | `renderUpdates` | 课程+资料更新时间线 |
| `/member/app/resources/<id>/download` | `handleResourceDownload` | 资料下载 |

会员中心侧边导航：首页 / 课程 / 资料库 / SOP / 更新 / 退出（`memberShell` L1271）。

## 三、管理后台（`adminShell` 统一布局，全部 SSR 骨架 + `admin.js` 驱动）

| 路由 | 模块 | 页面函数 / admin.js init | 主要 API |
| --- | --- | --- | --- |
| `/admin/` | 概览（未登录时兼登录/初始化页） | `adminOverviewBody` / `initOverview` | `/api/admin/overview` |
| `/admin/members/` | 会员管理 | `adminMembersBody` / `initMembers` | `/api/admin/members`、`/export`、`/audit` |
| `/admin/content/` | 课程管理（固定按分类分组） | `adminContentBody` / `initContent` | `/api/admin/contents*`、`/uploads/image`、`/categories`（下拉） |
| `/admin/categories/` | 课程分类管理（独立页） | `adminCategoriesBody` / `initCategoriesPage` | `/api/admin/categories*` |
| `/admin/cases/` | 案例管理 | `adminCasesBody` / `initCases` | `/api/admin/cases*`、`/uploads/image` |
| `/admin/tools/` | 工具管理 | `adminToolsBody` / `initTools` | `/api/admin/tools*` |
| `/admin/resources/` | 资料管理 | `adminResourcesBody` / `initResources` | `/api/admin/resources*`、`/file` 上传 |
| `/admin/settings/` | 网站设置 | `adminSettingsBody` / `initSettings` | `/api/admin/settings` |
| `/admin/copy/` | 文案管理 | `adminCopyBody` / `initCopy` | `/api/admin/copy`、`/copy/reset` |

后台导航数组位于 `adminShell`（`_worker.js` L1529 起），V1.0 隐藏「课程分类」「资料管理」入口即改这里。

## 四、公共布局现状（任务书第 8 点）

| 布局 | 实现 | 覆盖范围 |
| --- | --- | --- |
| 公开站页头/页脚 | `publicShell`（L1338） | 所有 Worker SSR 公开页 + 4 个静态文章页 + 首页（静态页结构一致，二期已统一） |
| 会员端布局 | `memberShell`（L1271） | 会员中心全部页面 |
| 后台布局 | `adminShell`（L1529） | 后台全部页面 |
| 微信咨询入口 | `settings` 表 `wechat_id` 等键，经 `applySiteSettings` 全站替换 | 公开站页脚、会员端、登录页均有 |
| 移动端/微信浏览器 | CSS 响应式（`style.css`/`member.css`/`admin.css`），登录与阅读场景已适配 | 二期已处理 |

**结论：页头页脚在二期已统一，未发现不同页面不一致的问题。** 静态栏目 index.html（不生效的冗余文件）除外，可在后续清理。
