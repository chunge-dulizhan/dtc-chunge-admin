## 2. 技术栈

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 托管/运行时 | Cloudflare Pages（Advanced Mode） | `public/_worker.js` 作为全站入口，运行在 Workers 运行时 |
| 服务端 | 原生 Worker JS（无框架） | 全部路由、鉴权、服务端渲染都在 `_worker.js`（约 6000 行） |
| 数据库 | Cloudflare D1（SQLite） | binding 名 `DB`，库名 `chunge-db` |
| 文件存储 | Cloudflare R2 私有桶 | binding 名 `R2`，桶名 `chunge-private-files` |
| 前端 | 原生 HTML/CSS/JS（无构建、无框架） | 静态页 + Worker 服务端渲染页混合 |
| 测试 | Node.js ≥22.5，`node:sqlite` 模拟 D1 | `tests/worker.test.mjs`（152 项测试，全部通过） |

## 4. 路由体系（`public/_worker.js` → `handleRequest`，L5907-6029）

请求分发顺序（自上而下，先匹配先生效）：

| 顺序 | 路径 | 处理函数 | 权限 |
| --- | --- | --- | --- |
| 1 | `/api/*` | `handleApi` | 按接口 |
| 2 | `/courses`、`/courses/`、`/library`、`/library/` | `handlePublicCourseList`（免费课程列表） | 公开 |
| 3 | `/guide/`、`/products/`、`/build/`（`/tutorials/` 别名）、`/marketing/` | `handleNavSection`（按 nav_category 动态栏目页） | 公开 |
| 4 | `/courses/<slug>/` | 302 跳 `/library/<slug>/` | 公开 |
| 5 | `/library/<slug>/` | `handlePublicLibrary`（免费课程详情） | 仅 free+published；member 课程 302 去登录 |
| 6 | `/cases`、`/cases/<slug>/` | `handlePublicCaseList` / `handlePublicCaseDetail` | 公开（仅 published） |
| 7 | `/tools/<slug>/` | `handleToolPage`（查库校验后放行静态页） | 按工具 access_level |
| 8 | `/media/<name>.<ext>` | `handleMedia`（静态目录→R2 `media/`） | 公开（仅图片文件名） |
| 9 | `/member/app/*` | `handleMemberApp`（会员中心 SSR） | 会员会话 active |
| 10 | `/admin/*` | `handleAdminPage`（后台 SSR） | 管理员会话 |
| 11 | `/courses/<slug>/attachment` | `handleContentAttachment`（课程附件下载） | 免费公开/会员校验 |
| 12 | 其余 | `env.ASSETS` 静态资源 | 公开 |

所有响应出口统一经过 `applySiteSettings`（L923）：按 `settings` 表与文案表做全站文案替换（品牌名、微信号、页脚等），静态页与 SSR 页都生效。

## 5. API 结构（`handleApi`，L4158-5686）

- 公开：`GET /api/health`、`GET /api/public/cases`、`GET /api/public/copy`
- 会员：`POST /api/member/login`、`POST /api/member/logout`、`GET /api/member/session`
- 工具计算：`POST /api/tools/<slug>/calc`（每次请求重新校验会员+工具状态）
- 后台（全部需管理员会话 + Origin 校验）：
  - 管理员：`/api/admin/setup`、`/login`、`/logout`、`/me`
  - 会员管理：`/api/admin/members`（GET/POST）、`/api/admin/members/export`、`/api/admin/audit`、`/api/admin/overview`
  - 网站设置/文案：`/api/admin/settings`、`/api/admin/copy`、`/api/admin/copy/reset`
  - 分类：`/api/admin/categories`（GET/POST）、`/api/admin/categories/<id>`（POST/DELETE）、`/api/admin/categories/<id>/migrate`
  - 课程：`/api/admin/contents`（GET/POST）、`/api/admin/contents/<id>`（GET/POST）、`/status`、`/delete`、`/attachment`（POST 上传）、`/attachment/remove`
  - 图片：`/api/admin/uploads/image`（课程/案例配图 → R2 `media/`）
  - 工具：`/api/admin/tools`（GET/POST）、`/api/admin/tools/<id>`、`/status`、`/delete`
  - 资料：`/api/admin/resources`（GET/POST）、`/api/admin/resources/<id>`、`/status`、`/delete`、`/file`（上传）
  - 案例：`/api/admin/cases`（GET/POST）、`/api/admin/cases/<id>`、`/status`、`/delete`

## 6. 部署配置（`wrangler.toml`）

- `name = "chunge-member-center"`，`pages_build_output_dir = "public"`
- `compatibility_date = "2025-11-01"`，`compatibility_flags = ["nodejs_compat"]`
- D1：binding `DB` → `chunge-db`（database_id 已写入配置，非敏感信息）
- R2：binding `R2` → `chunge-private-files`（私有桶，未开公开访问）

### 环境变量（Pages 项目设置，不落代码）

| 变量 | 必填 | 用途 |
| --- | --- | --- |
| `CODE_PEPPER` | 是 | 访问码哈希密钥；缺失时所有 API 拒绝服务（有意设计）。更换后全部访问码失效 |
| `ADMIN_SETUP_TOKEN` | 否 | 首次初始化管理员的额外校验令牌 |

### 部署流水线

GitHub main 分支 push → Cloudflare Pages Git 集成自动构建发布。也可 `npx wrangler pages deploy public` 手动上传。

## 7. 安全基线

- 全站安全响应头：`X-Content-Type-Options` / `X-Frame-Options: DENY` / `Referrer-Policy` / `Permissions-Policy`（`_worker.js` BASE_HEADERS + `public/_headers`）
- 会员 Cookie：`HttpOnly + Secure + SameSite=Lax`，30 天；管理员 Cookie 独立，12 小时
- 登录限流：IP + 访问码双维度，5 次失败锁 10 分钟（`login_attempts` 表）
- 写操作 Origin 校验（`originAllowed`）
- 富文本 HTML 服务端白名单过滤（`sanitizeHtml`，L587）
- 统一错误文案，不泄露内部信息；管理操作全部写 `audit_logs`
