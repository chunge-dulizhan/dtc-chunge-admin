## 二、每个页面的修改内容

### `/courses/` 免费课程列表
- 由单列文字列表改为**双列卡片网格**（手机端自动单列），卡片整块可点击。
- 每张卡片：封面（有 `cover_image` 时显示，否则用统一占位块，不生成假图）、标题、简介（最多 3 行）、免费标签、真实分类标签、更新时间、「开始学习 →」。
- 页头新增 `FREE COURSES` 标识与动态统计「共 N 门免费课程 · 无需登录即可阅读」，N 由查询结果实时计算。
- 空状态改为独立区块（含前往「独立站入门」的引导），不再是页面里的一行灰字。
- 查询仍为 `status='published' AND access_level='free'`，仅新增 `cover_image`、`updated_at` 两个展示字段。

### 免费课程详情 `/library/{slug}/`
- 面包屑由「首页 / 免费知识库 / 分类」改为「**首页 / 免费课程 / 分类**」，第二项可点击回 `/courses/`。
- 页尾新增「← 返回免费课程」按钮。
- 新增「继续学习」相关免费课程区块：按同栏目或同分类匹配、排除当前文章、最多 3 篇，**只取 `free + published`**；数据不足时不渲染该区块。
- 正文、章节切换、目录、附件下载、封面等既有结构完全保留，未截断任何内容。

### `/cases/` 案例列表
- 卡片新增「查看案例 →」入口，与摘要、分类、封面形成完整点击路径。
- 标题、介绍、总数、空状态沿用现有文案键与结构。

### 案例详情 `/cases/{slug}/`
- 新增案例简介区块（`.case-detail-summary`，橙色左边框），仅在 `summary` 存在时输出。
- 项目背景、实施过程、成果等正文按数据库实际内容渲染，未编造任何字段。
- 封面、面包屑、返回案例列表入口保留。

### 首页
- 仅案例卡片的客户端渲染同步加了「查看案例 →」，其余不动。

5. **案例详情使用 `SELECT *` 查询**：输出层只渲染白名单字段，测试已验证内部字段不出现；未改动查询方式以避免影响既有逻辑。
