# V1.0 升级风险清单

> 按「高 / 中 / 低」分级。V1.0 已确定的两个动作：取消后台「课程分类」独立入口、隐藏后台「资料管理」入口。

## 高风险

| # | 风险 | 说明 | 缓解 |
| --- | --- | --- | --- |
| H1 | 误删分类数据/接口 | 分类被课程表、资源表、会员首页 SOP 筛选、课程表单下拉、固定分组列表共 10+ 处依赖 | 只删 `adminShell` 导航一行；表、API、路由全保留 |
| H2 | 误删资料管理底层 | 资料下载被会员端 `/member/app/resources/`、`/sop/`、更新页依赖；R2 文件不可恢复 | 只删导航一行；接口、下载、R2 全保留 |
| H3 | 直接改库修「免费课程不显示」 | 若有人试图批量 UPDATE 现有课程 access_level/status，可能把会员课程公开 | 只改表单默认值/提示，不碰存量数据 |
| H4 | 环境变量误改 | `CODE_PEPPER` 变更会使全部会员访问码失效 | 升级全程不动 Pages 环境变量 |

## 中风险

| # | 风险 | 说明 | 缓解 |
| --- | --- | --- | --- |
| M1 | 隐藏分类入口后分类固化 | 现有 10 个课程分类不可再增删改排序；新课程只能归入现有分类或未分类 | 任务书已接受；保留隐藏路由 `/admin/categories/` 应急 |
| M2 | sop/prompt 分类 slug 被改 | 会员端 `/member/app/sop/` 按 slug 过滤，改名即空白 | 隐藏入口后无法改，风险反而消除 |
| M3 | 隐藏资料入口后无法上传新资料 | 只剩 API 可用 | 任务书已接受「暂时隐藏」语义 |
| M4 | 冗余静态栏目 index.html | `public/guide/index.html` 等 4 个文件被 Worker 拦截永不生效，易造成误解 | 标记冗余，V1.0 可不处理 |
| M5 | 首页「最新免费文章」静态写死 | 文案暗示自动更新，实际不变 | 第二阶段改动态接口或改文案 |

## 低风险

| # | 风险 | 说明 |
| --- | --- | --- |
| L1 | `_worker.js` 单文件约 6000 行 | 改动需全文件回归；有 152 项自动化测试兜底 |
| L2 | dev-server 不热重载 | 本地验证需重启进程 |
| L3 | D1/R2 无自动备份 | 升级前手动 `wrangler d1 export` 备份 |
| L4 | 工具数量认知差 | 任务书写 4 个工具，实际 5 个（多 `ai-sourcing`），需业务确认口径 |
