## 三、两级成长路线动态配置验证结果

1. **渲染函数单测**（`renderRoadmapStages` 命名导出，直接调用）：
   - 乱序输入 4 阶段（含 1 个 `visible:false`）→ 输出 3 个阶段且按 `order` 排序，隐藏阶段不出现；
   - 阶段内 topics 数量不等（2/3/0 条）、乱序、含隐藏项 → 全部按 `order` 排序输出，隐藏项不出现，0 条时不渲染 topics 容器；
   - 空配置 / null → 输出「成长路线整理中」空态，页面不崩；
   - 含 `<script>` 的名称 → 输出被 HTML 转义。
2. **结构校验**：`roadmap.json` 阶段 id 全局唯一、阶段内 topic id 唯一、`order` 均为数值、名称非空。
3. **端到端**：SSR 首页渲染出的阶段数量、阶段名称、每条学习内容名称与配置文件逐项一致（测试读取同一份 JSON 对比，而非写死期望值）。
4. **配置与展示分离**：改阶段数量/名称/说明/顺序/显隐、改 topics 数量/归类，只动 `roadmap.json`，无需改任何代码；页面无缓存（`Cache-Control: no-store`），保存即生效。
